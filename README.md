# 🔒 Security & Client Integrity

NULL is designed to stay **decoupled from central databases**, keeping supported user data on the client.

### LocalStorage Boundaries

Local information can include:

* Preferences
* Tab-cloaking metadata
* Panic key combinations
* Local calendars
* Active game states
* Visual settings

Clearing browser data or using the system reset option removes this local information.

### 🌐 Edge / Infrastructure Data

Normal hosting and CDN infrastructure can still process basic technical information such as:

* Public IP addresses
* Request headers
* Routing timestamps

This is normal web infrastructure used for maintaining availability and identifying network problems.

It does not mean NULL builds a personal tracking profile from that information.

# 🐛 Known Issues

NULL is still being developed, so a few things aren't perfect yet.

### ⛏️ Minecraft on School Wi-Fi

Minecraft can have **server and connection issues on school Wi-Fi**.

School filtering and other network configurations can interfere with Minecraft connections.

### ⚔️ Hollow Knight: Silksong

Silksong is one of the heaviest browser-based projects in NULL.

Depending on your device and browser, you may experience:

* ⏳ Very long loading times
* 💥 Crashing
* 🗂️ Other browser tabs crashing or becoming unresponsive
* ❌ The game not loading at all
* 💾 Around **13 GB of memory usage** in the browser tab

It's a pretty demanding game to run this way.

### 📱 Mobile Support

NULL is **not really built for mobile yet**.

Some games, controls, layouts, and UI features work much better on desktop.

### 🌐 Browser Differences

Some games and applications may behave differently depending on the browser or device.
